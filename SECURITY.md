# Security Policy

## Scope

This repository contains the GainiRen Security open-source platform.

## Reporting

Do not publish sensitive vulnerability details in a public issue. Use a private security disclosure channel when one is configured for the project.

Never commit passwords, API keys, private keys, database credentials, service-role keys, access tokens, or production secrets.

## Design principles

- Defense in depth
- Least privilege
- Secure defaults
- Explicit authorization boundaries
- Strong, standard cryptography only
- Replay resistance for signed requests
- Append-only security audit records where appropriate
- Data minimization and privacy-aware collection
- AI assists security decisions but is not the sole authority
